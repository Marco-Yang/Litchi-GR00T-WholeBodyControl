
1. **以上高速端等效惯量按照一级减速效率 0.95，二级减速效率 0.9 折算而来，为理论计算值，未实测。**
2. **不同供应商电机惯量可能略有差别，偏差值 3% 以内，建议仿真中针对串联关节增加少量 domain rand，并联关节可以稍微多加一些。**
3. **关节惯量计算公式：

   $$
   J_{output} = J_{motor} * N^2
   $$

   ，该值即为仿真中关节使用的惯量。**
4. **上述转速单位为 rpm，换算为 rad 需要乘以

   $$
   2*\pi / 60
   $$

   **
5. **注意一般峰值扭矩和峰值转速无法同时达到，同时额定转速针对 90% 以上场景即可满足需求，可在这些场景下直接使用额定转速作为训练的速度限幅，保证关节始终能够在一个稳定输出足额力矩的情况下运转，降低 sim2real 难度。**
6. **并联关节等效**

   1. **下肢 J5，J6 为并联关节，一般仿真中训练使用串联的 ankle_roll 和 ankle_pitch 关节**

      1. **ankle_pitch 折算的等效关节惯量为 5.333 * J_output（对应 78-58 电机），等效最大力矩 118.2，等效速度限幅 10.8 rad/s；**
      2. **ankle_roll 折算的等效关节惯量为 1.66562 * J_output（对应 78-58 电机），等效最大力矩 54.75，等效速度限幅 19.37 rad/s；**
   2. **腰部的 roll pitch 也为并联，一般仿真中也是使用串联的等效关节**
   3. **waist_pitch 折算的等效关节惯量为 7.3 * J_output （对应 78-58 电机），等效最大力矩 115，等效速度限幅 9.24785 rad/s；**
   4. **ankle_roll 折算的等效关节惯量为 1.21 * J_output（对应 78-58 电机），等效最大力矩 46，等效速度限幅 22.7 rad/s；**
   5. **注意以上值只是大致的计算值，实际惯量、限幅是和pitch/roll 的姿态相关的，且非对角，实际应用中使用估算值即可。**
